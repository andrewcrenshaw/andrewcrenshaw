### What I'm Building

**[Autogenous Synthesis Forge](https://andrewcrenshaw.dev/autogenous-synthesis/)** — An AI-first development OS. An autonomous orchestrator decomposes tickets, dispatches 12+ specialist agents against machine-verifiable acceptance criteria, enforces TDD, and auto-revises on failure. Persistent scratchpads survive context limits; 150+ automated test suites turn quality into binary pass/fail. ~80% reduction in review load.

**[Strata](https://andrewcrenshaw.dev/strata/)** — Autonomous job-search operating system. Eight specialized agents collaborate through governed PostgreSQL to discover, evaluate, match, and help apply to jobs. Three-layer dedup eliminates 95% of noise before LLM scoring. Two public PyPI libraries: [strata-harvest](https://github.com/andrewcrenshaw/strata-harvest) · [strata-match](https://github.com/andrewcrenshaw/strata-match).

**Alexandria / Living Memory** — Persistent memory architecture for agents: a metabolic knowledge graph where institutional knowledge compounds across sessions through assumption registers, decision-quality tracking, and drift detection.
